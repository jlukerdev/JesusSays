## Title Style Guidelines (Summary)

### Formatting
- **Capitalization:** Title case (first word + all proper nouns; don't capitalize "the" after first word unless it's a proper noun context)
- **Punctuation:** No trailing periods or exclamation marks
- **Abbreviations:** Spell out (don't use "Mt." for Matthew; use "Matt" if abbreviating)
- **Articles:** Include "The" at the start when it sounds natural; omit if redundant

### Language
- **Voice:** Use active voice where possible ("Love Your Enemies" not "Being Loving to Your Enemies")
- **Clarity:** Avoid theological jargon; a non-expert should understand the core teaching
- **Specificity:** Name the specific teaching type (e.g., "The Ten Commandments" not just "Commandments")

### Length
- Hard limit: **10 words**
- Target: **3–6 words** (most titles fall here naturally)
- All examples above comply

### Distinguishability
- Each teaching's title should be distinct enough to identify it in a list
- Avoid generic titles ("Jesus Teaches About..." not acceptable)
- If two teachings in the same category touch similar themes, their titles should distinguish them

## Quality Assurance Checklist per Title

When creating or reviewing a title, verify:

- [ ] **≤10 words?** Count each space-separated token
- [ ] **Clear to a non-expert?** Would someone unfamiliar with the passage recognize it?
- [ ] **Matches the teaching's core content?** (not a tangential detail)
- [ ] **Consistent format** with similar teachings in the same category?
- [ ] **Parables exact from TAG_RULES?** (if applicable)
- [ ] **I AMs in John's phrasing?** (if applicable)
- [ ] **Woes in "Woe for" format?** (if applicable)
- [ ] **No trailing punctuation?**
- [ ] **Title case applied?**
- [ ] **Memorable and distinctive?**
